# QuantumLogic – IT-Services & Lösungen

Persönliche Portfolio-Website für **QuantumLogic**. Statische Single-Page-Website in reinem HTML/CSS/JS – ohne Build-Schritt, ohne externe Abhängigkeiten.

## Inhalt

- **`index.html`** – die komplette Website (HTML, CSS und JS inline)
- **`assets/`** – Logo und Grafiken
  - `logo-mark.png` – freigestelltes Markenzeichen (Navigation, Hero, Über uns, Footer)
  - `quantumlogic-og.png` – Vorschaubild für Social Media (Open Graph)
  - `favicon-32.png`, `favicon-180.png` – Favicon & Apple-Touch-Icon

## Abschnitte

Hero · Leistungen · Branchenlösungen · Ablauf · Über uns · Vorteile · Kontakt · Footer
