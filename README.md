# LogicFlow – IT-Services & Lösungen

Persönliche Portfolio-Website für **LogicFlow**. Statische Single-Page-Website in reinem HTML/CSS/JS – ohne Build-Schritt, ohne externe Abhängigkeiten.

## Inhalt

- **`index.html`** – die komplette Website (HTML, CSS und JS inline)
- **`assets/`** – Logo-Varianten und Grafiken
  - `logo-mark.png` – freigestelltes Markenzeichen (Navigation, Footer, Hero)
  - `logicflow-logo-transparent.png` – vollständiges Logo mit Schriftzug (freigestellt)
  - `logicflow-og.png` – Vorschaubild für Social Media (Open Graph)
  - `favicon-32.png`, `favicon-180.png` – Favicon & Apple-Touch-Icon
